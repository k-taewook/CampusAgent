# CampusAgent 1~15주차 프로젝트 계획

작성일: 2026-05-18  
현재 주차: 12주차

## 1. 계획 개요

CampusAgent는 대학생의 과제, 일정, 공지사항, 학생 정보 검색을 하나의 대화형 인터페이스에서 처리하는 로컬 AI 시스템이다.  
이 문서는 프로젝트를 처음부터 끝까지 어떻게 진행할지 1주차부터 15주차까지 순서대로 정리한 전체 계획 문서다.

전체 방향은 다음과 같다.

- 초반 주차에서는 주제 정의, 요구사항 분석, 시스템 설계를 진행한다.
- 중반 주차에서는 핵심 기능 구현과 UI, 에이전트 구조, 데이터 저장 구조를 완성한다.
- 후반 주차에서는 새로운 기능 확장보다 기존 프로그램 보완, 안정화, 최종 발표와 최종보고서(논문) 작성을 중심으로 진행한다.
- 현재 기준으로 기능 개발은 11주차까지의 구현 범위를 기준으로 마무리하고, 12주차부터는 기존 기능 정리와 발표, 최종보고서 준비가 중심이 된다.

이 시기에는 다음 내용을 진행한다.

- 기존 과제, 일정, 공지 검색, 학생 정보 검색 기능의 동작 점검
- UI에서 시연 흐름이 어색한 부분 보완
- 오류 메시지, 예외 처리, 빈 결과 안내 등 사용성 개선

- 최종보고서에 들어갈 시스템 구조, 구현 기능, 한계점 정리 시작
- Multi-Agent 구조는 이번 프로젝트의 구현 범위에서 제외하고, 향후 개선 방향으로 정리

12주차가 끝나면 새로운 기능 개발은 종료하고, 이후 일정은 발표 준비와 최종보고서 완성에 집중한다.

## 16. 최종 정리

이 계획은 1주차부터 15주차까지 프로젝트 전체 흐름을 처음부터 끝까지 이어서 보여주기 위한 문서다.

전체 흐름을 한 문장으로 정리하면 다음과 같다.

- 1~10주차는 분석과 핵심 기능 구현 단계다.
- 11주차는 핵심 기능 보완과 시연 가능한 기능 정리 단계다.
- 12~15주차는 기존 프로그램 보완, 최종 발표 준비, 최종보고서 작성 단계다.

즉, CampusAgent는 11주차까지의 구현 범위를 기준으로 기능 확장을 닫고, 12주차부터는 발표와 최종보고서 제출까지 포함한 프로젝트 마무리 단계로 들어간다.
